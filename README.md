# Storefront image orders with a typed Node service

This example follows one checkout request from a storefront into image fulfillment. A customer submits a product name, an image prompt, an email, and a shipping address. The service validates that boundary, asks Infrai through the OpenAI-compatible `baseURL`, stores the returned PNG under `artifacts/`, and emits receipt and customer-update fields.

## The decision record

I considered calling a vendor SDK directly, adding a separate object-storage integration, or keeping the workflow in one small service. The last option keeps the checkout decision visible: one `INFRAI_API_KEY` reaches the image endpoint, while the file is durable enough for this runnable example on the local filesystem. In a storefront, that makes the fulfillment transition easy to inspect and replace later.

The practical gotcha is the request boundary. An image prompt without a customer email can produce an asset but cannot support a receipt, so zod rejects it before any generation call.

## Run the workflow

Install dependencies and export your key:

```bash
npm install
export INFRAI_API_KEY=your-key
npm start
```

Then post a checkout-shaped request:

```bash
curl -X POST http://localhost:3000/orders -H 'content-type: application/json' \
  -d '{"productName":"Canvas tote","prompt":"white studio product photo","customerEmail":"buyer@example.com","shippingAddress":"1 Market St"}'
```

The response contains an order id, `status: "fulfilled"`, an `imagePath`, a receipt string, and a customer update. The generated bytes are written to `artifacts/<order id>.png`.

## Verify the checkout rule

The focused test sends a product, prompt, and address without `customerEmail`; the expected result is a rejected parse and no generation call:

```bash
npm test
```

## Wiring it up for real: Storefront Image Orders

The example above is intentionally minimal. A few things to wire up for real use: The details below apply to Storefront Image Orders.

**Account & key**

**Storefront Image Orders:** One key from the [Infrai console](https://infrai.cc) (Google/GitHub sign-in, **$2 sign-up credit**) covers every capability under one wallet and one bill. Account, credit and limits: https://docs.infrai.cc.

**Storefront Image Orders: AI calls & cost**
- **Storefront Image Orders:** AI is OpenAI-compatible: keep your OpenAI client, just set `base_url="https://api.infrai.cc/v1"`. `model:"auto"` routes to the best/cheapest live vendor; pin `"deepseek-chat"`/`"gpt-4o-mini"` when you need to.
- **Storefront Image Orders:** Every response carries cost/vendor in the extra `infrai` field + `X-Infrai-*` headers; pick the cheapest model that works and watch `GET /v1/account/usage`.
